# Exercices de programmation

Voici le repo de mon projet d'aventure textuel dans l'interface de commande

## Contenu Actuel

- `Tools\` : contient tout mes fichiers uttilisables séparéments par mon programme principal
- `Games\` : Contient tout les fichiers Json de définitions des jeux
- `main.py` : mon programme principal
- `manoir.json` : le fichier json donné par le professeur et définissant un jeu que mon programme principal doit pouvoir lire et comprendre sans erreurs

## Lancer le jeu

```
python main.py
```
